Nama Proyek		: Website Inventaris Layanan Laboratorium Terpadu
Kategori		: Sistem manajemen inventaris berbasis website
Deskripsi proyek	: Membangun sistem berbasis web untuk mengelola data inventaris laboratorium secara terstruktur, meliputi pencatatan aset, pemantauan kondisi, pengelolaan histori, dan mutasi barang antar laboratorium.
Tujuan: Menyimpan data barang laboratorium secara digital dan terstruktur, Menampilkan informasi detail barang (nama, kode aset, tipe, spesifikasi, kondisi, ketersediaan), Mempermudah pencarian dan monitoring data inventaris, Mencatat histori perubahan kondisi dan perpindahan lokasi setiap aset, Memfasilitasi mutasi aset antar laboratorium secara satuan maupun massal, Mengurangi kesalahan pencatatan manual dan meningkatkan akurasi data
