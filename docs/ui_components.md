\# UI Components - CCTV Lalu Lintas Karesidenan Kediri



\## 1. Splash Screen

Halaman pembuka aplikasi sebelum masuk ke sistem utama.



Komponen:

\- Logo aplikasi

\- Nama aplikasi

\- Loading animation



\---



\## 2. Public Home Page

Halaman utama publik untuk memantau CCTV lalu lintas.



Komponen:

\- Sidebar

\- Map

\- Daftar CCTV

\- CCTV preview card



\---



\## 3. Login Admin Page

Halaman autentikasi administrator.



Komponen:

\- Input username

\- Input password

\- Tombol login

\- Validasi form

\- Alert error login



\---



\## 4. Dashboard Admin

Halaman utama administrator setelah login.



Komponen:

\- Sidebar

\- Header dashboard

\- Statistik CCTV



\---



\## 5. CRUD CCTV Page

Halaman pengelolaan data CCTV.



Komponen:

\- Table data CCTV

\- Tombol tambah CCTV

\- Tombol edit CCTV

\- Tombol hapus CCTV

\- Modal form CCTV

\- Search bar

\- Pagination table



\---



\## 6. CCTV Card Component

Komponen kartu untuk menampilkan CCTV.



Isi:

\- Nama CCTV

\- Alamat CCTV



\---



\## 7. Modal Form Component

Digunakan untuk tambah/edit data CCTV.



Field:

\- Nama CCTV

\- Lokasi CCTV

\- Latitude

\- Longitude

\- URL Stream CCTV

\- Status CCTV

\- Tombol Simpan CCTV
